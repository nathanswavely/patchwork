# The name is Quilthost

The platform is named Quilthost: plainly descriptive (it hosts quilts —
Patchwork's own word for an instance), needing no explanation for anyone
who has seen the product. Brand domain quilt.host if available, else
quilthost.com; free subdomains live on the same brand apex
(lancasterarts.quilt.host), submitted to the Public Suffix List, covered
by one wildcard certificate.

Two names were rejected for documented reasons. **"Patchwork
Hosting" / patchwork.com**: patchwork docs/adr/025 warns the flagship
must never read as "the" official center — a host wearing the project's
own name maximizes the WordPress .com/.org confusion and makes every
self-hoster look unofficial. Adjacent, never identical. **"Patchhost"**:
in the project's glossary a patch is a single community entity (one
band, one venue), while the hosted unit is a whole quilt — the name
would say "we host bands" to anyone fluent in the product's own
vocabulary. Also considered: Longarm (exact service metaphor, but
requires quilting literacy the audience doesn't have), The Bee (names
free communal labor while billing a subscription), Quilt Rack.
