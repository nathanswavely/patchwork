# Quilthost seeds

Founding documents for **Quilthost**, the managed hosting service for
Patchwork instances (the hosting arm anticipated by docs/adr/025). These
are NOT patchwork docs: they seed the separate quilthost repo's
CONTEXT.md and docs/adr/, and should move there — directory deleted from
this repo — the moment that repo exists. They live here only because
they were produced while planning against this repo's ADRs and glossary,
and needed a durable home before the quilthost repo was created.
