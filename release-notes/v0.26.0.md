The largest release so far. A person can now delete their account, take a copy
of the quilt they can see, and point followers at wherever they have moved to —
the three doors ADR 012 said a community platform owes the people in it. Around
that: a contact card that is shared one patch at a time, a noticeboard for the
members' room, and address suggestions for instances that install a gazetteer.

## Upgrading

Nothing to do. `docker compose pull && docker compose up -d`.

Seven migrations run on first boot (062–068). All of them add tables or
columns; none rewrite or drop anything, so the previous image still reads the
database if you need to roll back.

Two things worth knowing, neither of which requires action:

- **Contact cards convert themselves.** The old three-column card becomes
  contact items on first boot, and each patch a person had ticked "share
  contact" for receives one share row per item. The old columns are left in
  place and unread — a later release retires them, once no deployment can
  still be mid-upgrade. Nobody's disclosure widens in the process.
- **The bundled Caddyfile dropped its explicit `X-Forwarded-For` override.**
  Caddy's `reverse_proxy` already ignores a client-supplied value and sets the
  header from the connecting address, so the line was duplicating the default.
  If you run another proxy in front of Caddy, `server.trusted_proxies` in
  `patchwork.yaml` is the setting that matters. An edited Caddyfile of your own
  is untouched by an image pull.

## Security

- **maplibre-gl 5.24 → 6.9**, closing a critical upstream advisory. This ships
  in the frontend bundle, so updating the image is the whole fix.

## Changes

**Leaving, and taking your things**

- Self-serve account deletion. The person is erased and their acts are kept: a
  vote keeps its voter, a proposal keeps its author, and the username is
  retired rather than freed. Refused while you are the only admin of a patch.
- Any member can export the quilt as they see it, in the import format, without
  asking an admin — enough to seed a fork.
- A patch or a person can publish a "we've moved" pointer. The old home keeps
  working and says where the new one is.

**The members' room**

- A noticeboard with flat replies, visible to admins and members only, with its
  own report queue that never reaches the instance panel.
- A contact card is now a set of items — phone, email, handle, note — each
  shared with one patch at a time. Nothing is shared by a default or a standing
  rule: joining a patch later starts shared with nothing, and a promotion grants
  nothing.

**Governance**

- On a patch where the maintainer decides, the maintainer decides every
  proposal and may put one to an advisory vote first.
- A reported person is told when a warning is issued.
- Withdrawing a join request is its own act, distinct from leaving a patch you
  were actually in.
- An admin can prove they hold the role to an outside party without naming
  anybody — the statement carries the domain and the claim, never a person.
- Governance repos rebuild themselves from the canonical rows after a restore
  or a seamrip import, and say in the history where they were rebuilt.

**Maps and discovery**

- Optional local gazetteer: typing a patch's address offers a marker to
  confirm. Built offline, copied in as a file, nothing fetched at runtime. An
  instance without one behaves exactly as before.
- The patch profile splits into a head and its glimpses, and a tap on a tile
  hands back the patch itself rather than a card about it.
